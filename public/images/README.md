# Imágenes

Por ahora hay marcadores de color con el nombre de cada foto. Reemplázalos por fotos de referencia (Unsplash o Pexels, que tienen licencia libre) y después por las fotos reales, **siempre con el mismo nombre de archivo**, así el sitio no cambia.

Formato: `.jpg` exportado a calidad 80, idealmente bajo 300 KB cada una. Más adelante se pueden convertir a `.webp`.

## Para la sesión de fotos real

- Salón armado para un evento de equipo, sin decoración de temporada (banderines, guirnaldas).
- Una toma general con luz de día y otra de tarde con luces encendidas.
- Grupo de 10 a 20 personas compartiendo, idealmente sin mirar a cámara.
- Fotos horizontales para hero y secciones, cuadradas o verticales para galería.
